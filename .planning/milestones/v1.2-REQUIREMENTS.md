# Requirements: VideoSummary v1.2 knowledge-base

**Defined:** 2026-05-03
**Core Value:** 把视频提炼成对学习者真有教学价值的 Markdown 文档（不是字幕翻译），并保持全流程 ¥0
**Milestone Goal:** 把 23+ 条已总结视频从"一摞独立 markdown"升级为 Claude-queryable 知识库 — 用户用自然语言提问，Claude FIRST ACTION 读 `output/.index.json` 给出 top-N 推荐 + chapter 入口，所有索引自动生成
**Source:** `.planning/v1.2-CANDIDATES.md` (9 D-XX architectural decisions locked)

## v1.2 Requirements

每条需求 = 一个 atomic、testable、user-centric capability。Requirements 分 4 个 category：INDEX（索引架构）/ TOPIC（taxonomy governance）/ BACKFILL（一次性补齐）/ PROMPT（Claude 推荐入口）+ 1 个 OPTIONAL category（CLI 兜底）。

### INDEX (per-slug + 顶层聚合)

- [ ] **KB-01**: per-slug `output/<slug>/index.json` 中颗粒 schema lock — `slug / title / duration_s / mode / topics[] / keywords[] / tldr_oneliner / chapters[]`，其中 `chapters[]` 每项 = `title + start + 1-2 行 excerpt`（**无独立 keywords 字段**，per D-02 颗粒度决策）
- [ ] **KB-02**: index.json 在 `/summarize-video` Phase 7.6 自动生成（Phase 7 写完 summary.md 之后、Phase 8 cleanup 之前）；老归档 backfill 复用同一个 generator 保证一致性
- [ ] **KB-03**: keywords 抽取优先复用 `output/_glossary.md` 已有 H2 anchors 作 candidate set（per D-03 来源决策）；新概念才创造新 keyword，避免术语分裂（"LoRA / Lora / low-rank adaptation"）
- [ ] **KB-04**: 顶层聚合 `output/.index.json` 在每次 per-slug index.json 写入后自动 rebuild — 扫所有 `output/*/index.json` 扁平合并，atomic write；schema = `{"<slug>": <per-slug-index>, ...}` 无 backlink 字段（per D-07）
- [ ] **KB-05**: `python -m agent.tools index rebuild` 手动兜底 CLI — 适用 backfill 一键收尾 + debug edge case；具备 stale detection（per-slug index.json 比顶层 .index.json 新时显式提示）
- [ ] **KB-06**: D-29 byte-equal 守不破 — `index.json` 是新 sidecar 文件，不进 `scripts/replay_v10_archives.py` 比对范围；v1.2 close phase 时 33/0/30 byte-equal 仍 PASS

### TOPIC (taxonomy governance)

- [ ] **KB-07**: `output/_topics.md` governance 文件结构 — 顶部 = 已批准 taxonomy（按 category 树状）；底部 = `# Pending` 段（Claude 申请的新 topic 待 user review）
- [ ] **KB-08**: `python -m agent.tools topics bootstrap` CLI — 一次性扫 17 archives 的 summary.md，Claude 归纳出初始 taxonomy，写到 `_topics.md` 顶部已批准段（首次 bootstrap 默认批，因为 ground truth）
- [ ] **KB-09**: `python -m agent.tools topics audit` CLI — 列所有 pending + 各 topic 引用计数 + 孤儿 topic 检测；支持 `--json` flag for Claude consumption
- [ ] **KB-10**: `python -m agent.tools topics resolve <pending-name> [--rename <new>]` CLI — 把 pending 挪到正式 topic 段，自动更新所有引用 index.json
- [ ] **KB-11**: Claude 写 index.json 时 governance 锁定 — topics 必须从已批准段选；不合适 → append 到 `# Pending` 段（必填字段：申请来源 slug + chapter title + 提议理由），该 chapter `topics: ["pending: <name>"]`（K5 边界延伸到 governance）

### BACKFILL (一次性补齐 17 archives + 6 队列)

- [ ] **KB-12**: 17 v1.0/v1.1 archives 一次性 backfill — `python -m agent.tools index backfill --all` 给所有 `output/<slug>/` 写 index.json（idempotent：已有 index.json 默认 skip，`--force` 覆盖）
- [ ] **KB-13**: backfill error tolerance — 单 slug summary.md 损坏 → 该 slug 失败但其他继续，最后一次性报告失败列表；6 队列视频不需要 backfill（处理时新流程同步生成）

### PROMPT (Claude 推荐入口 — CLAUDE.md prompt rule)

- [ ] **KB-14**: CLAUDE.md 加 prompt rule 段 — 锁定触发 phrase 集合（'推荐' / '相关' / '我之前看过' / '学过' / '找一下我' / '哪些视频' / 类似查询意图）；FIRST ACTION = `Read output/.index.json`；`.index.json` missing 时 hint user 跑 `index rebuild`
- [ ] **KB-15**: 推荐回复格式锁 + anti-hallucination — 每条推荐 = 1 行 slug+title+共享匹配信号 + 1 行 tldr + 1-3 个 chapter 入口（mirror v1.1 5th format-spec invariant 的字面规则风格）；FORBIDDEN 编造 .index.json 里没有的 slug；FORBIDDEN 推荐不存在的视频（mirror v1.1 anti-hallucination 模式）

### OPTIONAL (兜底 CLI — 顺手做)

- [ ] **KB-MISC-01**: `python -m agent.tools index search/list` CLI 兜底 — `index search <query>` keyword 子串匹配（text 输出 + `--json` flag）；`index list [--topic <topic>] [--mode <mode>]` 按 filter 列；放 v1.2 末尾，可 drop 给 v1.3 如时间紧

## Future Requirements

Deferred to future milestone (v1.3+). Tracked but not in v1.2 roadmap.

### Cross-summary Backlinks (rejected per D-07，可未来重审)

- **KB-FUT-01**: index.json 加 `related_slugs` 字段 + summary.md `## 相关推荐` 段
- **KB-FUT-02**: 跨 summary 关联走 explicit backlink（不再依赖 Claude 即时计算）

> **Why deferred:** D-07 用户原话"先 drop 吧，作用也不大"。single-user 23 条规模 over-engineering；scale 长到 50+ 条且 Claude 即时推荐变慢时再启用。

### Slash Command Entry Points (rejected per D-09，可未来重审)

- **KB-FUT-03**: `/recommend-videos <query>` slash command — 显式调用而非 phrase 触发
- **KB-FUT-04**: `/show-video <slug>` 快速跳转

> **Why deferred:** D-09 用户已习惯自然语言；slash command 是 nice-to-have；少加一个 phase。如果发现自然语言触发漏判率高（误触发 / 漏触发）再加。

### Advanced Search Features

- **KB-FUT-05**: 日期范围过滤 / mode-specific keyword scoring / fuzzy match
- **KB-FUT-06**: SQLite-backed index（替代扁平 .index.json）

> **Why deferred:** 23-条 single-user corpus 不需要复杂搜索；JSON 5-10KB 体积 Claude 一次 Read 无压力。corpus 长到 200+ 条时再引入。

## Out of Scope

Explicitly excluded for v1.2. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| 任何付费 API for keyword extraction (LLM API for topic classification) | ¥0 hard constraint；KB-03 复用本地 `_glossary.md` 即足；K5 决策权在 Claude in-context，不外移到 LLM API |
| Markdown index files (`output/.index.md`) | D-01 锁定：消费者 = Claude（不是用户 grep）；`_glossary.md` 已是术语索引，Markdown 索引职责重叠 |
| Per-chapter independent keywords field | D-02 锁定：颗粒度 = summary keywords + chapter 导航锚点；chapter 内重复抽 keywords 是过度切碎（用户原话"逐个遍历 chapter 不太合理"） |
| Cross-summary "## 相关推荐" section in summary.md | D-07 锁定：backlinks dropped；跨 summary 关联走 Claude 即时 Read .index.json，不写入 summary 文件 |
| Slash command for recommendations | D-09 锁定：自然语言入口足够；不增加 phase |
| 17 archives summary.md 内容 mutation for index 生成 | D-29 invariant：summary.md / segs.json / paragraphs.json / meta.json 4 个核心文件 byte-equal 保留；index.json 是 NEW sidecar |
| 自动 promote pending topics 到批准段 | D-04 K5 边界：governance 是用户决策（虽然偶尔 review）；自动 promote 会破坏"用户偶尔 governance"的设计意图 |
| Auto-cleanup of orphan topics | KB-09 audit 报告 orphan，但不自动删；用户 review 后用 `topics resolve --remove` 手动清（如果未来加这个 flag） |
